# 我的世界服务器怎么开：不敲命令行，从选配置到朋友进服的完整步骤

搜这个关键词的人，卡住的地方通常不在最后一步。真正让人开不起来服的，是前面三个没人提前告诉你的选择：Java 版还是基岩版、放自己电脑还是租机器、几个人玩。这三个问题答完，路线就定死了，后面基本都是照做。

先把这三分岔口说清楚，再讲怎么买、怎么开、怎么让朋友进得来。

## Java 版和基岩版：开服方式完全不是一回事

这一步搞错，后面全白费。

- **Java 版**：PC 端（Windows / macOS / Linux），插件和模组生态最全，走 **TCP 25565** 端口。
- **基岩版**：手机、主机、Win10 版，走 **UDP 19132** 端口，用的是官方 BDS 服务端。
- 两边不能直连。手机玩家想进 Java 服，需要 Geyser + Floodgate 这类跨版本方案，配置量不小，新手别一上来就折腾。

大多数教程默认讲 Java 版，因为玩家基数大、插件多。如果你队伍里有人只用手机，先想清楚是要劝他换设备，还是直接开基岩服。

## 开服前必须对上的三个参数

### 1. 游戏版本决定 Java 版本

这是新手最常翻车的地方：Java 装错，服务端直接启动失败，报错还看不懂。

| 我的世界版本 | 需要的 Java |
| --- | --- |
| 1.16 及以下 | Java 8 |
| 1.17 – 1.20.4 | Java 17 |
| 1.20.5 及以上 | Java 21 |

玩整合包的话反着来：先确认整合包要求哪个游戏版本，再倒推该装哪个 Java。

### 2. 服务端类型决定你能装什么

| 服务端 | 适合场景 | 插件 / 模组 |
| --- | --- | --- |
| 官方原版 | 纯原版生存 | 都不支持，性能一般 |
| Paper | 想装插件又要流畅 | 兼容 Bukkit / Spigot 插件，是多数人的选择 |
| Purpur | 基于 Paper，想要更多自定义项 | 同 Paper |
| Forge | 玩模组整合包 | 模组生态最成熟 |
| Fabric | 轻量模组、新版本适配快 | 启动快，适合少量模组 |

一句话：纯生存用 Paper，玩整合包按整合包要求选 Forge 或 Fabric，原版服务端基本只有测试时才用。

### 3. 端口和协议别搞反

Java 版 TCP 25565，基岩版 UDP 19132。放行规则里协议选错，服务器跑得好好的，外面就是连不上。

## 配置怎么选：单核性能比核心数重要

游戏主逻辑跑在单线程上，所以主频高的 CPU 比核心多的 CPU 更有用。这一点直接决定你花钱的优先级。

内存是另一条线，几个实测过的经验值：

- 服务端本体基础占用约 1–1.5GB
- 每个在线玩家额外 200–400MB
- 每个模组额外 50–200MB

按人数粗略对照：

| 玩法 | 玩家数 | 建议配置 |
| --- | --- | --- |
| 原版 / Paper 纯净生存 | 2–5 人 | 2核4G |
| 原版 + 常用插件 | 5–15 人 | 2核4G – 4核8G |
| 中型模组服 | 5–15 人 | 4核8G 起 |
| 大型整合包（200+ 模组） | 不限 | 4核8G 起，越往上越稳 |

还有一个很多人不知道的差异：1.18 以上版本对性能的消耗大约是 1.16 的两倍、1.12.2 的三倍。开高版本服别拿老攻略的配置表照搬，视距（view-distance）从默认值往下调两格，效果往往比加一核 CPU 明显。

## 两条开服路线，先选对再动手

**路线一：自家电脑 + 内网穿透。** 优点是不要钱。代价是家庭宽带上行有限、电脑不能关、还得处理路由器和防火墙，穿透方案免费版通常限制连接数。适合三五个人试玩一周。

**路线二：租云服务器。** 不用管网络配置，晚上不玩服务器也在线，缺点是每月固定支出。这是长期开服的正常选择。

云服务器里又分两种，这个区别比价格更重要：

- **普通 VPS**：给你一台完整的系统，Java、服务端 jar、端口全要自己装自己配。自由度高，也更容易配错。
- **面板服**：商家把运行环境预装好了，你在网页后台点几下就能起服。现在很多面板支持一键开服和配置升降级。

不熟悉 Linux 的话，第二类能省掉一整个下午的排查时间。

## 从注册到朋友进服：完整流程

1. **注册并绑定微信**，把首月 5 折券领到手。
2. **进控制台 → 游戏云 → 购买游戏云**。
3. **选服务器类型**：新手直接选雨云面板，要系统权限选 VPS。
4. **选游戏与版本**：Minecraft Java 版（或基岩版），版本按你和朋友玩的版本选，服务端类型按前面的表挑。
5. **选机型、区域、配置**：高版本模组服优先高主频 CPU；配置按人数对照表来，别一上手就冲最高档。
6. **选计费模式**：经常玩选固定计费，偶尔玩选动态计费。
7. **选购买时长**，下单时会让你选在线模式还是离线模式——有正版账号选在线，没有选离线，之后也能在配置文件里改。
8. **进面板开服**：控制台的"云产品 → 游戏云"里点管理，就是面板后台。传整合包可以用在线文件管理或 SFTP。
9. **改配置**：把 `eula.txt` 里的 `eula=false` 改成 `eula=true`，否则服务器不会启动。然后在 `server.properties` 里设 `max-players`、`view-distance`、`motd`。用 SFTP 编辑脚本时记得把编码切成 UTF-8，不然中文全是乱码。
10. **把地址给朋友**：NAT 机型是"地址:端口"的形式，端口在面板里能看到；如果加了独立公网 IP，就是"IP:25565"（基岩版 19132）。

## 开服后最容易踩的坑

**服务器启动了又立刻关闭。** 九成是没同意 EULA，去 `eula.txt` 改。

**自己能进，朋友进不来。** 检查端口和协议对不对（Java 是 TCP），以及给朋友的地址里有没有带上端口号。

**正版朋友进服报"无效会话"。** 服务端开了在线验证但你用的是离线客户端，或者反过来。改 `server.properties` 里的 `online-mode` 再重启。

**人一多就卡。** 先看 TPS，掉到 20 以下再谈加配置。多数情况是实体和掉落物堆积，或者视距开太大，先用清理类插件处理，比直接升级划算。

**存档丢了。** 面板自带备份和计划任务，把定时备份打开，几分钟的事，能省掉一个月的进度。

**谁都能进服搞破坏。** 打开白名单，把朋友 ID 加进去。这一步很多人图省事跳过，出事之后才后悔。

## 几个常被问到的问题

**不买服务器能开服吗？** 能。自家电脑加内网穿透就是零成本方案，代价是电脑要常开、上行带宽有限、稳定性看运气。长期玩还是会转到云服务器。

**2核4G 能带多少人？** 纯净生存 5 到 12 人，看版本和视距；装几十个模组的话基本只够一个人跑。1.18 以上的版本别拿这个配置硬撑。

**面板服能开模组服吗？** 能。面板的 Minecraft 支持列表里包含 Forge、NeoForge、Fabric 以及多个混合端，装整合包通常是通过纯 Java 环境上传服务端实现的。

**手机玩家能进 Java 服吗？** 不能直连。要么开基岩版服务器，要么在 Java 服上装 Geyser + Floodgate 做跨版本支持，配置量不小，建议先确认队伍里到底有几个人只用手机。

**第一次开服该买哪个？** 3 到 5 个朋友玩原版或轻插件，面板的入门配置配合首月 5 折券就够用，用 1 元试用确认能跑起来再续费。真到了十几个人、模组上百个的阶段，再考虑升级配置或换 VPS，那时候你已经知道自己缺什么了。
